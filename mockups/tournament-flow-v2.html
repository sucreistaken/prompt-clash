📌 ARAŞTIRMADAN GELEN TASARIM KARARLARI

• Bracket sahneye çizilmez (128'lik ağaç okunmaz) → sahnede KALAN sayacı + küçülen duvar + düello kartı; tam ağaç adminde (esports/Eurovision pratiği).

• Kaybeden = jüri (P1b→P2→P3): %75–98 eleniyor; auto-spectate + oy hakkı = loser-retention motoru (Jackbox audience, Fortnite spectate).

• Yumuşak iniş: "KAYBETTİN" yok; "Top 24 / 76 kişiyi geçtin" + paylaşım kartı (anti-rage-quit).

• Belirsiz reveal (S4): sonucu drumroll'dan önce gösterme; 2 sn "judging…" + telefon titreşimi (dopamin beklentide zirve yapar).

• Streak + near-miss (P1a, S3): galibiyet serisi ateşi + kıl-payı oy barları "2 oyla kaybettin" gerilimi.

• İzleyici MVP (P4): doğru oylayan elenen de kazanır → ikinci dopamin döngüsü, herkes hep oyunda.

• Mizah/absürt: Hall of Fame/Shame (S6) + absürt konular = "kötü sonuç daha komik" (Gartic/Skribbl ruhu).
